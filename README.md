# CONNECT AI - Version 2 (姿勢＆動作バイオメカニクス分析ツール)

BlazePose（TensorFlow.js / MediaPipe）を用いた、ブラウザで動作するリアルタイム姿勢アライメント・動的機能運動分析ツールです。
本バージョンは **GitHub Pages での即時公開・ホスティングに対応**しており、HTTPS環境下でスマートフォンやPCのカメラを用いた姿勢分析がスムーズに行えます。

---

## 🚀 主な機能
1. **静的姿勢アライメント評価**: 前面、後面、左側面、右側面の4方向からの姿勢分析。
   - ケンダルの姿勢分類（Swayback、Flatback、Kyphosis-Lordosis、Neutral）の自動推定。
   - 骨盤傾斜角（前傾・後傾）の目視スライダー補正およびASIS連動。
2. **左右荷重比率のリアルタイム算出**: 上半身・下半身・全身の重心位置（Center of Mass: COM）を算出し、左右の過負荷を可視化。
3. **足底圧中心（COP）動揺分析**: 重心動揺の軌跡（Path）、95%信頼楕円（Sway Area）、動揺速度（Speed）をレーダーチャートにリアルタイム描画。
4. **動的機能評価 (FMS/OHS)**:
   - オーバーヘッドスクワット（前面・側面）における膝のニーイン（Valgus）、体幹前傾、腕の挙上制限の測定。
   - 片脚立位バランステスト（重心動揺面積の自動記録）。
   - 立位体前屈・体後屈テスト（股関節屈曲角度の自動測定）。
   - 肩関節複合可動性テスト（背中での両手結び距離のpx計測）。
5. **フレーム送り再生＆関節点のD-pad手動補正**:
   - 録画したデータをタイムラインで1フレームずつ再生・検証。
   - AIの関節点の推定がズレている場合、画面タップで選択し、十字キー（D-pad）でピクセル単位で手動補正が可能。
6. **ローカル履歴保存 (IndexedDB)**: 測定データ（座標ログ、アライメント角、左右比）をブラウザ内に保存。CSVエクスポートや動画出力にも対応。
7. **Gemini API 連携によるAI臨床インサイト**:
   - Google Gemini API と直接連携し、詳細な姿勢分類、潜在的怪我リスク、推奨リハビリトレーニングメニューのレポートを数秒で自動生成。
   - APIキー未設定の場合は、ローカルのルールベース診断エンジンがレポートを自動生成。

## 🌐 GitHub Pages へのデプロイ・公開手順

GitHub Pages を使用すると、**SSL（https://）通信が提供されるため、スマートフォンやタブレットのカメラから直接アクセスして使用できるようになります。**

### ステップ 1: GitHubでリポジトリを作成
1. [GitHub](https://github.com/) にサインインします。
2. 右上の「**+**」ボタンから「**New repository**」を選択します。
3. リポジトリ名（例：`connect-ai`）を入力し、公開設定を **Public** にして、「**Create repository**」をクリックします。

### ステップ 2: ローカルからコードをプッシュ
PCのターミナル（PowerShell や Git Bash など）を開き、本プロジェクトディレクトリ (`connect-ai-v2`) で以下のコマンドを実行します：

```bash
# Gitリポジトリを初期化
git init

# 全てのファイルをステージング
git add .

# 初回コミットを作成
git commit -m "Initialize CONNECT AI V2 with Modular Files"

# メインブランチに名前を変更
git branch -M main

# リモートリポジトリ（GitHub）の紐付け（※URLはご自身のリポジトリのものに変更してください）
git remote add origin https://github.com/あなたのユーザー名/リポジトリ名.git

# GitHubにコードをプッシュ
git push -u origin main
```

### ステップ 3: GitHub Pages の有効化
1. GitHub上のリポジトリページを開き、上部の「**Settings（設定）**」タブをクリックします。
2. 左サイドバーから「**Pages**」をクリックします。
3. **Build and deployment** セクションの「Branch」設定で、`None` から **`main`** に変更し、ディレクトリを **`/ (root)`** のままにして、「**Save（保存）**」をクリックします。
4. 1〜2分待つと、画面上部にデプロイされたURLが表示されます：
   `https://あなたのユーザー名.github.io/リポジトリ名/`

このURLにスマホやPCでアクセスすれば、どこからでもカメラを起動して姿勢測定が行えます！

## 💻 ローカル環境でのテスト実行方法
Webカメラアクセス（`getUserMedia`）や IndexedDB のセキュリティ仕様上、HTMLファイルを直接ダブルクリックして開く（`file://`パス）と動作しません。ローカル環境でテストする場合は、以下の方法で簡易Webサーバーを立ち上げてください。

### Python を使う方法 (最も簡単)
WindowsのコマンドプロンプトやPowerShellを開き、`connect-ai-v2` ディレクトリに移動して以下を実行します：

```cmd
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` にアクセスします。

### Node.js (npx) を使う方法
```bash
npx serve
```

## ⚙️ Gemini APIキーの設定方法
1. アプリを起動し、上部の「**⚙️ API設定**」ボタンをクリックします。
2. Google AI Studio などから取得したご自身の Gemini APIキー を入力して「設定を保存」をクリックします。
3. ダッシュボードを開き、「ダッシュボード」または「レポート」を表示させると、自動でGemini APIが測定データに基づいた評価・リハビリトレーニングメニューの提案を作成してくれます。
